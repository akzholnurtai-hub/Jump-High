# Jump High

A 3D mobile platformer made in Unity 6 for Game Development Fundamentals (Narxoz University).
Run across floating platforms, collect every coin to open the door, survive three levels and beat the boss.

- **Engine:** Unity 6000.6.0f1 (URP), Input System 1.20.1
- **Platform:** Android / iOS, landscape
- **Scenes:** MainMenu → Level1 → Level2 → Level3_Boss → Win
- **Author:** Akzhol Nurtai

## Controls

| Phone | Keyboard | Action |
|---|---|---|
| Joystick (bottom left) | WASD / arrows | Move |
| JUMP (bottom right) | Space | Jump |
| FIRE (next to JUMP) | Right mouse button | Shoot |
| II (top right) | Esc | Pause |

## Mobile UI (Assignment 8–9)

- Canvas Scaler: Scale With Screen Size, 1920 × 1080, Match = 1 (landscape)
- Every HUD element anchored to its corner; buttons and text inside a `SafeArea` panel (`Assets/Script/SafeArea.cs`)
- Pause screen (`Assets/Script/PauseMenu.cs`): Resume, Restart, Menu; `Time.timeScale = 0` while paused
- Tested in Device Simulator: 16:9 phone, notch phone (19.5:9), 4:3 tablet

The UI is generated by the editor menu **RK2 → Build Mobile UI** (`Assets/Editor/RK2Setup.cs`).
